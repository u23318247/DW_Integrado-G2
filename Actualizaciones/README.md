## 🚀 Principales Módulos Actualizados
1. **Frontend Angular 21/22:** Arquitectura Standalone, Signals reactivos, control flow `@if` / `@for`, y catálogo dinámico con 180 prendas categorizadas.
2. **Backend Spring Boot 3:** Arquitectura en capas (Controller, Service, Repository, DTO, Entity), seguridad JWT en cookies HttpOnly y persistencia con JPA/Hibernate.
3. **Ecosistema de 7 APIs Externas Integradas:**
   * API RENIEC (Consulta de DNI)
   * API Tipo de Cambio Oficial (USD / PEN en vivo)
   * Pasarela de Pagos PayU Latam Sandbox
   * Asistente Virtual Inteligente (IA de Moda)
   * Mapas y Geolocalización (OpenStreetMap + Leaflet)
   * Autenticación Social (Google Sign-In API)
   * API de Notificaciones y Comprobantes por Correo Electrónico
