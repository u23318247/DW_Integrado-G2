# Laboratorio 11: Fundamentos de Angular, Componentes y SASS/SCSS

Este laboratorio corresponde a la **Semana 11 de Desarrollo Web Integrado (Unidad 3)**:
- Entorno Node.js + npm + Angular CLI.
- Componentes Standalone.
- Control de Flujo nativo (`@if`, `@for`, `@empty`, `track`).
- Estilos avanzados con SASS/SCSS (variables, mixins, partials y anidamiento).
- Panel de métricas y dos componentes hijos modulares (`app-header`, `app-footer`, `summary-panel`).
