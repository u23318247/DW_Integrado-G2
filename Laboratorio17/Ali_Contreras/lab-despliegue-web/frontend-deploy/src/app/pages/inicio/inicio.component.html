Despliegue Web con Docker y Nginx

Arquitectura de Microservicios con Reverse Proxy | Estudiante: Ali Contreras

Arquitectura del Despliegue

1 Cliente / Navegador Puerto 8081 (Externo)
2 Nginx (Frontend) Servidor Web + Reverse Proxy
3 Spring Boot (Backend) Puerto 8080 (Red interna Docker)
  • Red Bridge interna segura (app-network).
  • Sin problemas de CORS mediante redirección Nginx /api/.
  • Contenedor multi-stage build con Node.js 20 y Alpine Nginx.

Comandos de Despliegue en Producción (Docker Compose)

# Construir imágenes y levantar ambos contenedores en segundo plano:
docker compose up -d --build

# Verificar que los contenedores estén corriendo:
docker ps

# Visualizar logs en tiempo real:
docker compose logs -f

# Acceso en el navegador:
# Frontend Angular + Proxy: http://localhost:8081
# Endpoint Backend directo:  http://localhost:8080/api/estado
